# Working name: PlatformZero

The name fits a general platformer-learning project and is short enough for a package and repository. It is a working name, not a completed trademark clearance.

Known collisions found during this preparation:

- PlatformZero, an AI platform engineering service: https://www.platformzero.ai/
- Platform Zero, a platform game by ThomasHope: https://thomas-hope.itch.io/platform-zero
- A historical PLATFORMZERO US trademark opposition record: https://ttabvue.uspto.gov/ttabvue/ttabvue-91270548-OPP-12.pdf

The historical record is not a conclusion about current registration status or permission to use this name for this project. Adding Lab does not automatically resolve a collision. Search availability does not establish legal clearance.

Suggested positioning: General-purpose 2D platformer agents and fast simulation, starting with Celeste. Celeste should identify a supported game adapter, not imply endorsement or ownership.
