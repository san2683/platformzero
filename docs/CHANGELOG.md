# Changelog

- First installable, dependency-free synthetic headless backend and CLI.

- Added exact continuation, physics/terminal, CLI and spawned-worker tests.
- Added actual-frame/decision benchmarks with measured local CPU results.
- Native-game adapters, Celeste maps/importer, rendering and learning pipelines remain outside this release.
